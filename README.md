# middle-click-close

A GNOME Shell extension: middle-click a window thumbnail in the Overview to close it.

## Install

```bash
mkdir -p ~/.local/share/gnome-shell/extensions/middle-click-close@local
cp metadata.json extension.js ~/.local/share/gnome-shell/extensions/middle-click-close@local/
gnome-extensions enable middle-click-close@local
```

Log out and back in.

## Compatibility

GNOME Shell 45–51.
